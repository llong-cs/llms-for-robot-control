# Procedural assets

Geometry definitions live in [ditto/tasks](../src/ditto/tasks) and are generated by [ditto/assets.py](../src/ditto/assets.py) on first environment creation. The cache is `data/generated/ditto-bench/v1`, relative to the project root.

Task props are built from shared primitive descriptions used for rendering and collision. Concave shapes are assembled from convex parts so slots, holes, and ring openings remain open in the physics geometry. Task definitions also specify materials and mass properties, which affect contact and stability.

The generator exports meshes and geometry specifications and reuses them across runs. Changes to the generator or its geometry dependencies produce new cache entries. To change a task or difficulty, edit its definitions in `ditto/tasks`; cached meshes are generated outputs.

Upstream robot, table, camera, and shared YCB resources: [MolmoAct2 / ManiSkill installation](../../docs/INSTALLATION.md).
